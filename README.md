## ✦ The vision

**NexCompiler** is a Compiler Construction course project designed to make compilation feel visible, understandable, and powerful. Rather than treating code as a black box, the application will guide users through the stages that transform a program into meaningful output.

Our planned goal is to support **C**, **C++**, and **Java** through a clean interface where students can write code, explore compiler stages, understand errors, and learn how language tools work beneath the surface.

> This project is currently in its discovery phase. The final feature set and technical design will be decided after course requirements are confirmed.

## ⚡ Planned experience

| Stage | What NexCompiler aims to reveal |
| :--- | :--- |
| `01` · Source | Write or paste C, C++, or Java code in one focused workspace. |
| `02` · Lexical analysis | See how source text becomes tokens. |
| `03` · Syntax analysis | Explore the program structure and parsing results. |
| `04` · Semantic checks | Surface meaningful type, scope, and logic errors. |
| `05` · Output | Present compilation feedback and execution-ready results clearly. |

## ✨ Why NexCompiler?

- **Multi-language ambition** — a single learning space for C, C++, and Java.
- **Built for understanding** — compiler stages should be explained, not hidden.
- **Beautiful by design** — technical tools can still feel fast, clear, and welcoming.
- **Course-focused** — scope will align with the Compiler Construction curriculum.
